AB29 TRAINING
=============
index.html is the whole app — nothing else needed.

TO PUT IT ONLINE (GitHub Pages)
  1. Make a new repository on github.com.
  2. Upload index.html to it (keep the name exactly as it is).
  3. Repo Settings > Pages > Source: "Deploy from a branch", branch "main", folder "/ (root)".
  4. A minute later your link is https://<your-username>.github.io/<repo-name>/

YOUR WEEK
  Mon Push · Tue Easy Run · Wed Pull · Thu Legs · Fri Upper · Sat Long Run · Sun Rest
  The Today screen suggests whatever the plan says, and the seven-day strip at the
  top shows the week at a glance — gold is today, green is done.
  Change any day in Library > My Week. You can still pick anything you like on the day.

LOGGING SETS
  Type a weight, reps or RPE into a set and it copies down into the set below,
  flashing gold for a moment. It only fills the next row, and never overwrites a
  number you typed there yourself or a set you have already ticked.

NOTES
  Your history saves in whichever browser you open it in. Back it up now and then
  from Library > Settings > Export backup.
  The email key is inside this file — if the repo is public, anyone could read it
  and use it to email you. Regenerate it at web3forms.com if that becomes a nuisance.
